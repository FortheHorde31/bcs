# Хелперы

Готовые помощники под конкретные рабочие задачи. Скачал папку, открыл у себя — работает.

**Чем отличается от скиллов.** Скилл из [`skills/`](../skills/) — это договорённость, которую агент подхватывает молча в фоне: попросил сверстать лендинг — он сделал по нашим правилам. Хелпер работает наоборот: он **ведёт диалог**. Задаёт вопросы, ждёт ответов, проверяет, что получилось, и отдаёт готовый документ. Ты с ним разговариваешь, а не просто ставишь задачу.

Поэтому хелпер — это папка, которую забираешь целиком и держишь у себя: внутри не только инструкция для агента, но и материалы, шаблоны и место, куда складываются результаты.

## Что здесь есть

| Хелпер | Для чего | Сколько занимает |
|---|---|---|
| [`brif-landing-page`](brif-landing-page/) | Заполнить бриф на лендинг или страницу сайта так, чтобы у исполнителя не осталось вопросов. Спрашивает по одному, не принимает расплывчатых ответов, всё незакрытое собирает в реестр пробелов с адресатами | 10–15 минут голосом, ~20 текстом |

## Как забрать

Скачать одну папку без клонирования всего репозитория:

```bash
npx degit FortheHorde31/bcs/helpers/brif-landing-page brif-landing-page
```

Либо клонировать репозиторий целиком и взять нужное:

```bash
git clone https://github.com/FortheHorde31/bcs.git
```

Дальше — по инструкции внутри папки хелпера. Работает в Claude Code, Cursor, Cowork и на claude.ai; в первых двух достаточно открыть папку, в остальных — загрузить её как скилл.

## Первое, что стоит сделать

У хелперов бывают файлы, которые заполняются под свою команду — например `CONTACTS.md` с адресатами, у кого уточнять недостающее. Репозиторий публичный, поэтому имён в них нет, только роли. Впиши своих людей в скачанной копии.

## Как добавить свой хелпер

1. Папка `helpers/<имя>/` — коротко, в нижнем регистре, через дефис.
2. Внутри `SKILL.md` с фронтматтером `name` и `description` — по нему агент понимает, когда хелпер нужен. Пиши в описание живые формулировки, которыми задачу ставят люди, а не определение.
3. `README.md` — **для человека, а не для агента**: что это, как скачать, как запустить, что настроить первым делом. Это единственное, что увидит тот, кто зайдёт в папку.
4. Обнови таблицу в этом файле.
