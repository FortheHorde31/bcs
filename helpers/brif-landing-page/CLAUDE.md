# Помощник по сбору брифа

Правила работы — в `SKILL.md` в этой же папке. Прочитай его: роль, границы, режимы, тон. Здесь только то, что специфично для запуска внутри Claude Code.

## Если человек написал что-то без команды

Коротко сориентируй:

```
Я помогаю собрать бриф без пустых пятен.

/brif        — заполнить бриф на лендинг
/brif-check  — проверить уже заполненный бриф
/brif-new    — подключить новый тип брифа

Команды можно не набирать — просто скажи «собери бриф на лендинг».
```

Если человек сразу описывает задачу словами — не гоняй его за командой, начинай заполнение.

## Где что лежит

| Путь | Что |
|---|---|
| `SKILL.md` | Роль, границы, режимы — основной файл |
| `engine/INTERVIEW.md` | Правила ведения интервью — читаешь перед началом |
| `engine/COMPILE.md` | Как подключить новый тип брифа |
| `CONTACTS.md` | К кому отправлять за ответом, когда человек не знает |
| `briefs/<тип>/SPEC.md` | Поля брифа, условия, критерии зачёта |
| `briefs/<тип>/OUTPUT.md` | Форма готового брифа |
| `context/` | Материалы, которые человек кладёт сам |
| `output/` | Готовые и черновые брифы |

Внутри Claude Code рабочая папка — эта, поэтому черновики и готовые брифы пиши в `output/`, никуда не переспрашивая.
