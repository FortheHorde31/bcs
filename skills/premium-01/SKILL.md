# Premium 01 — визуальный язык

Стиль из лендинга-фаворита **«Умножаем инвестиции»** (`bcs_mi/10. Landing pages/bcs_x2_v.2_tilda`). Задача скилла — переносить **облик** (цвета, типографику, форму, приёмы, тон) на любой новый лендинг. **Структуру не копируем** — набор и порядок секций диктует конкретный лендинг; переиспользуем стиль.

Если из запроса не ясно, что за лендинг и какие секции нужны, — сначала уточни задачу, потом применяй язык.

> Стиль отвечает только за облик. Если готовый лендинг надо пересобрать в блоки для конструктора Tilda — это отдельный скилл **`tilda-export`**.

## Суть языка в одном абзаце

Премиальная редакционная эстетика в духе «old money»: светлый фон, глубокий тёмно-синий как основной «чернильный» цвет, **один** синий акцент для действий, золото — только как тонкий премиум-штрих, и мягкие пастельные плитки для категорий. Ключевой почерк — **засечный шрифт Prata на всех заголовках, крупных числах и ценах**; интерфейсный Golos Text — на всём остальном. Тон спокойный, без агрессивного маркетинга: «мы уверены и никуда не торопимся».

## 7 правил, которые делают этот стиль узнаваемым

1. **Prata на числах и заголовках, Golos Text на тексте.** Крупная цифра/цена/H1-H3 — всегда `'Prata', Georgia, serif`, вес 400. Никогда не набирай числа-героев интерфейсным шрифтом.
2. **Один синий.** `#006DFF` — только действия и ссылки. Не разбавляй вторыми синими; глубину даёт `#001A3D`, а не второй акцент.
3. **Золото — редко и тонко.** `#E0BA82`: подчёркивание под H1, знак `×2`, акцент на тёмном фоне. Это приправа, а не заливка.
4. **Eyebrow с нумерацией секций.** Каждая секция начинается с `01 · Призы` — Golos 600, `letter-spacing:.16em`, uppercase, цвет `#5A6B83`.
5. **Гигантский призрачный serif-номер** в углу плиток/карточек: Prata ~74–320px, цвет `rgba(0,26,61,.06)`, `pointer-events:none`. Фирменная деталь.
6. **Пастельные плитки категорий** (мятная / персиковая / лавандовая) с цветным uppercase-лейблом — так различаются группы призов/фич.
7. **Тёмные премиум-блоки** на `#001A3D` (финал, промо-CTA, футер) с золотым акцентом и призрачным числом — ритмические «якоря» страницы.

## Токены

Полная таблица и drop-in CSS — в [tokens.css](tokens.css). Скопируй `:root`-блок в новый лендинг и обращайся к переменным. Кратко:

| Роль | Значение |
|---|---|
| Фон страницы | `#F7FAFF` |
| Чернила / заголовки | `#001A3D` |
| Текст вторичный | `#33465F` |
| Приглушённый / caption | `#5A6B83` |
| Синий акцент (CTA, ссылки) | `#006DFF`, hover `#0354D7` |
| Голубой тинт (плашки, треки, selection) | `#CCE2FF`, заливка секции `rgba(204,226,255,.4)` |
| Золото | `#E0BA82` (градиент `#F8E4BC→#EBCA92→#E0BA82→#C89B57`), тёмное `#6B4A16` |
| Зелёный рост / позитив | линия `#0F8A4C`, мятная плитка `#D6F5E5`, live-точка `#00DC6E` |
| Пастель: персик | плитка `#FAE5D1`, лейбл `#CC6600` |
| Пастель: лаванда | плитка `#EAD4F7`, лейбл `#5B1782` |
| Тёмная секция | фон `#001A3D`, текст `#F7FAFF` / `rgba(247,250,255,.65)` |
| Хайрлайны | `rgba(0,26,61,.10–.13)`; сильные линии-разделители `rgba(0,26,61,.35–.40)` |

**Типографика.** Prata (serif, 400) — заголовки/числа/цены; Golos Text (400/500/600) — всё остальное. H1 `clamp(56px,6.6vw,90px)/1.03`, letter-spacing `-.015em`; H2 `clamp(36px,4.2vw,52px)/1.1`; body 15–19px/1.6; eyebrow 12px/600/.16em/uppercase.

**Форма.** Радиусы: карточки 20–28px, большие баннеры 28–32px, пилюли и чипы 999px, круглые иконки 30–36px. Контейнер `max-width:1240px`, паддинг `0 48px` (моб. 24px). Вертикальный ритм секции — `padding:104px 48px` (моб. ~64px). Тени мягкие сине-чернильные: `0 30px 80px rgba(0,26,61,.16)`, `0 18px 50px rgba(0,26,61,.14)`.

**Моушн.** Появления `translateY(6–14px)+fade`; live-точки пульсируют opacity; hover — кнопки темнеют, карточки `translateY(-5px)`, строки подсвечиваются `rgba(204,226,255,.28)`. Easing `cubic-bezier(.2,.8,.2,1)`. Уважай `prefers-reduced-motion`.

## Как применять к новому лендингу

1. **Не начинай с копирования секций.** Определи, какие блоки нужны этому лендингу (герой, оффер, шаги, FAQ, футер — свой набор).
2. Заложи фундамент: фон `#F7FAFF`, шрифты Prata + Golos Text, контейнер 1240px, токены из [tokens.css](tokens.css).
3. Каждой секции дай eyebrow с нумерацией и H2 на Prata.
4. Числа-герои (цены, сроки, метрики) — Prata. Это главный переносимый признак стиля.
5. Расставь ритм: 1–2 тёмных `#001A3D`-блока как якоря, пастельные плитки для категорий, золото 2–3 раза за страницу максимум.
6. Все действия — синие пилюли `#006DFF`; второстепенные — outline.
7. Проверь по чек-листу «7 правил» выше: если убрать Prata с чисел или добавить второй акцентный цвет — стиль ломается.

## Юридика (для BCS-лендингов РФ)

Тёмный футер несёт обязательные дисклеймеры: лицензии ООО «Компания БКС», «не является индивидуальной инвестиционной рекомендацией», отсутствие страхования вкладов, сноски по условиям акции, 18+. Формулировки и грейды рейтингов — сверять с юристами/PR перед релизом (не выдумывать цифры). Тестовые публикации — с `noindex/nofollow` до согласования.
