# Материалы

Клади сюда всё, из чего помощник может предзаполнить бриф:

- страницу продукта (текстом или PDF)
- старую версию лендинга
- лендинги конкурентов
- выгрузку из Метрики
- презентацию по продукту, условия, тарифы
- переписку, где обсуждалась задача

Помощник прочитает всё, что здесь лежит, вытащит подходящие факты и пометит источник у каждого значения. Проверять всё равно нужно — но набирать руками не придётся.

Папка в гит не уезжает: материалы бывают непубличными.
