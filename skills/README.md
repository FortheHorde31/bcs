# Skills

Агентские скиллы для работы над продуктами БКС.

**Скилл** — это папка с файлом `SKILL.md` и вспомогательными материалами. `SKILL.md` содержит YAML-фронтматтер (`name`, `description`) и инструкцию на человеческом языке. Агент (Claude Code, Codex) читает описания всех доступных скиллов, сам решает, какой подходит под задачу, и подгружает инструкцию в контекст. То есть скилл — это не код, а упакованный воспроизводимый способ сделать работу так, как мы договорились её делать.

Зачем: каждая задача «сверстай лендинг в нашем стиле» или «перенеси это в Tilda» иначе решается заново и по-разному. Скилл фиксирует договорённость один раз.

## Что здесь лежит

| Скилл | Тип | О чём |
|---|---|---|
| [`premium-01`](premium-01/) | Стиль | Визуальный язык лендингов БКС: navy + gold + пастель, засечный Prata на заголовках и числах, Golos Text в тексте. Токены, компоненты, 7 правил стиля. |
| [`tilda-export`](tilda-export/) | Платформа | Пересборка готового лендинга (единый HTML) в самодостаточные блоки для конструктора Tilda: статик-блоки T123/Zero и Popup-блок. |

## Как это устроено: стиль и платформа разделены

Раньше это был один скилл, и он смешивал два разных вопроса — «как это выглядит» и «как это попадает в продакшн». Разделили:

- **Скиллы стиля** отвечают только за облик: цвета, типографику, форму, приёмы, тон. Структуру страницы они не задают — набор секций диктует конкретный лендинг.
- **Скиллы платформы** отвечают только за упаковку: как готовый HTML превращается в то, что вставляется в конструктор.

Так любой стиль можно вывезти в Tilda, и любой новый способ доставки не придётся дублировать в каждом стиле.

### Конвенция именования стилей

Один визуальный стиль = один отдельный скилл с уникальным именем-серией: `premium-01`, дальше `premium-02`, `premium-03`. Не пытаемся уместить несколько стилей в один скилл — агент не сможет выбрать между ними.

В именах скиллов допустимы **только буквы, цифры и дефис**. Подчёркивание ломает загрузку — поэтому `premium-01`, а не `premium_01`.

### Что кладём в скилл стиля

```
premium-01/
  SKILL.md        # суть языка, правила, токены таблицей, как применять
  tokens.css      # drop-in :root с переменными — копируется в новый лендинг
  components.md   # рецепты разметки: кнопки, плитки, баннеры, хедер, аккордеон
```

## Как подключить у себя

Скиллы читаются из глобальной папки агента. Скопировать нужный:

```bash
# Claude Code
cp -R skills/premium-01 ~/.claude/skills/
cp -R skills/tilda-export ~/.claude/skills/

# Codex
cp -R skills/premium-01 ~/.codex/skills/
```

Либо симлинком, чтобы правки в репозитории подхватывались сразу:

```bash
ln -s "$(pwd)/skills/premium-01" ~/.claude/skills/premium-01
```

После этого агент подхватит скилл автоматически — вызывать вручную не нужно, достаточно поставить задачу («сделай лендинг в стиле premium-01», «перенеси это в Tilda»).

## Как добавить новый скилл

1. Создай папку `skills/<имя>/` — имя короткое, в нижнем регистре, через дефис.
2. Напиши `SKILL.md` с фронтматтером:
   ```yaml
   ---
   name: <совпадает с именем папки>
   description: <что делает + КОГДА применять, с ключевыми словами и формулировками, которыми задачу ставят живые люди>
   ---
   ```
   `description` — самое важное поле: по нему агент решает, брать скилл или нет. Пиши в него триггеры, а не только определение.
3. Тяжёлые материалы (таблицы, референсы, длинные примеры) выноси в соседние файлы и ссылайся на них из `SKILL.md` — он подгружается целиком, держи его компактным.
4. Обнови таблицу в этом README.
