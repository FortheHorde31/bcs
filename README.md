# BCS

Рабочий репозиторий продуктовой команды сайтов экосистемы БКС — `bcs.ru`, `bcs-express.ru`, `bcs-bank.ru`.

Здесь живёт всё, что мы делаем руками и вместе с агентами: агентские скиллы, инструменты, лендинги, дизайн-язык и рабочие материалы. Идея простая — один раз договориться, как мы что-то делаем, и зафиксировать это так, чтобы в следующий раз не собирать заново.

## Структура

| Папка | Что внутри |
|---|---|
| [`skills/`](skills/) | Агентские скиллы. Сейчас — `tilda-export`: пересборка готового лендинга в блоки конструктора Tilda. Подробности и конвенции — в [skills/README.md](skills/README.md). |

Репозиторий только начат — разделы добавляются по мере переезда материалов.

## Что такое скиллы и почему они здесь главные

Скилл — папка с `SKILL.md`: YAML-фронтматтер (`name`, `description`) плюс инструкция на человеческом языке. Агент читает описания всех скиллов, сам выбирает подходящий под задачу и подгружает инструкцию в контекст.

Это способ хранить не код, а **договорённости**: как выглядит наш лендинг, как он уезжает в Tilda, какие правила ломать нельзя. Разница между «сверстай что-нибудь» и «сверстай по нашему скиллу» — в воспроизводимости результата.

Ключевой принцип раскладки: **стиль и платформа — разные скиллы**. Скилл стиля отвечает за облик, скилл платформы — за упаковку в продакшн. Так стили и способы доставки комбинируются, а не дублируются.

## Как пользоваться

Склонировать и подключить скиллы к своему агенту:

```bash
git clone https://github.com/FortheHorde31/bcs.git
cd bcs
cp -R skills/tilda-export ~/.claude/skills/
```

Дальше агент подхватывает их сам — достаточно поставить задачу словами.

## Соглашения

- **Имена скиллов** — только буквы, цифры и дефис, в нижнем регистре. Подчёркивание ломает загрузку.
- **Стили нумеруются**: `premium-01`, `premium-02`, … Один стиль — один скилл.
- **Источник правды — этот репозиторий.** Локальные копии в `~/.claude/skills/` синхронизируются вручную (или симлинком, см. [skills/README.md](skills/README.md)).
- **Цифры и формулировки не выдумываем.** Юридические дисклеймеры, лицензии и рейтинги в материалах для лендингов сверяются с юристами и PR перед публикацией.
- **Репозиторий публичный** — внутренние цифры, непубличные материалы и доступы сюда не кладём.
