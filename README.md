# БКС · Навигатор — лендинг v3

Иммерсивный scroll-лендинг: Three.js (WebGL-мир) + GSAP ScrollTrigger (режиссура) + Lenis (инерционный скролл). Без сборки — ES-модули и CDN.

## Запуск

```bash
cd bcs_navigator_v3
python3 -m http.server 8080
# открыть http://localhost:8080
```

(Нужен любой статик-сервер — importmap не работает с file://.)

## Структура

- `CONCEPT.md` — полная концепция: идея, нарратив, копирайтинг, дизайн-система
- `index.html` — 8 сцен, весь копирайт
- `css/main.css` — дизайн-токены, типографика, reveal-состояния
- `js/experience.js` — Three.js: частицы (GLSL-морф), траектории, золотой маршрут, маяки, орбиты, bloom
- `js/main.js` — Lenis + ScrollTrigger: мастер-таймлайн камеры и стейта

## Фолбэки

- `prefers-reduced-motion` — без инерции и дрейфа частиц
- нет WebGL — статичный градиент, весь контент читается
- мобильные — 7 000 частиц вместо 14 000, DPR ≤ 1.5, без bloom
